# Costing Method is chosen per Category and can be switched

The owner uses Moving Average but wants FIFO for clothing, and wants to be able to change the formula later. So the Costing Method is a per-Category setting. Every Stock Movement keeps its own unit cost whatever the method, and FIFO Categories also keep a Cost Layer per receipt. A switch takes effect from a chosen date and never revalues stock or restates past COGS: FIFO → Moving Average averages the remaining layers; Moving Average → FIFO starts from one layer at the current average cost.

## Considered Options

- One method for everything (Moving Average): simplest, but rejected because the owner asked for FIFO on clothing and Indonesian standards (PSAK 14) allow different cost formulas for inventory of a different nature.
